AZHAQ / SITE TYPE

Display: Hubot Sans Condensed SemiBold, presented as Hubot Display in CSS.
Body and UI: Hubot Sans Regular / SemiBold.
Code: Monaspace Krypton Regular.
The Azhaq wordmark is drawn vector lettering, independent of these fonts.

Fonts are self-hosted. Hubot WOFF files are lossless conversions of the
official static TTF sources. Monaspace uses the official static web font.

Source repositories:
https://github.com/github/hubot-sans
https://github.com/githubnext/monaspace
